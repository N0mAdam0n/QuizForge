QuestionBank Portable (Windows)
===============================

Run without installation
------------------------
1. Extract the complete QuestionBank-Portable folder to a writable location.
2. Double-click question-bank.exe.
3. On first launch, open the app and complete the setup wizard.

All writable application data is stored in the "data" folder beside the
executable. This includes the SQLite database, configuration, uploads,
generated media, embedded vector data and logs. The app does not use
%APPDATA%\QuestionBank in portable mode.

Do not run the executable from inside the ZIP archive. Keep the complete
extracted folder together, and make sure the current Windows user can write
to it. Avoid extracting under protected locations such as Program Files.

Backup and migration
--------------------
Exit QuestionBank from its tray menu before copying or moving the folder.
Copy the complete extracted folder to back up the application and all data.
The folder can be moved to another writable location or Windows computer.

This portable edition does not install a service or configure auto-start.
AI features require access to an AI provider configured in the application.
