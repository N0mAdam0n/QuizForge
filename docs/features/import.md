# 智能导入

智能导入让你上传原始素材，抽取成结构化题目，遵循 **上传 → 审核 → 入库** 三步流程。支持三种**解析方法**：

- **自动多策略**（默认）：先运行本地结构识别；题目拆分或字段完整度不足时再调用 AI。解答模式和图片识别使用 AI。
- **AI 智能抽取**：由 AI 自动识别题目结构，适用于格式不固定的文档与图片。
- **本地结构识别**：按显式标签或常见的题号、选项、答案/解析排版提取，**不依赖 AI**、即时且可控。

每次导入的文档会作为一个独立题库保存，不会把这份文档的内容混成一个没有边界的题目列表。审核确认时：

- 保存为稿件：题库保留在个人空间并标记为**待发布**；之后可在“我的题库”中打开并发布整个题库。
- 不保存为稿件：个人空间中有答案的题目直接发布；没有答案的题目保留为草稿。
- 共享空间仍需按学科审核规则审核发布。

发布后的完整题库可在自主练习页面按空间选择。题库内的题目可直接在题库详情中修改或移除。

## 支持格式

| 类型 | 扩展名 | 自动多策略 | AI 智能抽取 | 本地结构识别 |
|------|--------|:---:|:---:|:---:|
| Word | `.docx` | ✅ | ✅ | ✅ |
| Markdown | `.md` / 粘贴文本 | ✅ | ✅ | ✅ |
| 图片 | `.png` `.jpg` `.jpeg` `.webp` | ✅（视觉模型 OCR） | ✅（视觉模型 OCR） | — |

::: tip 前置条件
**自动多策略**仅在本地识别质量不足或进入解答/图片模式时依赖 AI；**AI 智能抽取**始终依赖已激活的模型：文本使用文本模型，图片使用**视觉模型**。请先在 [AI 供应商与模型](/admin/ai-config) 配置模型。**本地结构识别**无需 AI 配置；Word 转换出的图片引用会保留在题干或解析中，但本地策略不会对图片内容做 OCR。
:::

## 本地结构识别

当题库是可读取的电子文档时，可以使用本地识别。解析器先检查文档结构，再选择对应规则；无需按固定标签重排题目。也可使用默认的**自动多策略**，由系统在本地结果不完整时回退到 AI。

### 常见题号格式

支持以题号开头的题目行，后续选项、答案和解析可分别位于独立段落。题干中的 Markdown 图片引用会作为题干内容保留。

```
1. 根据图示网络，以下说法正确的是？ ![拓扑图](/static/media/task-id/image1.png)
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：A
解析：根据图中的网络结构判断。
```

可识别 `1.`、`1、`1.1.` 等常见题号；也支持 `A.`、`A、`A．`、Pandoc 转换产生的 `**A.**` 等选项标记，以及普通或加粗的“答案/参考答案/正确答案”“解析/详解”字段标签。题型可根据选项、答案和大题标题推断。

### 显式标签语法

已有标签模板仍然支持。用 `【题目】` 分隔每一道题；一道题从 `【题目】` 开始，到下一个 `【题目】`（或文末）结束。除 `【题目】` 外，其余标签**均可省略**。

#### 标签清单

用 `【题目】` 分隔每一道题；一道题从 `【题目】` 开始，到下一个 `【题目】`（或文末）结束。除 `【题目】` 外，其余标签**均可省略**。

| 标签 | 字段 | 说明 |
|------|------|------|
| `【题目】` | 题干 | **必填**，同时作为每题的分隔符 |
| `【题型】` | 题型 | 可写"单选/多选/判断/填空/解答"；省略时自动推断 |
| `【选项】` | 选项 | 块内写 `A. … B. … C. …`；或用 `【选项A】【选项B】` 逐项 |
| `【答案】` | 答案 | 选择题写字母（多选如 `AB`），判断题写 `对/错` |
| `【解析】` | 解析 | 可多行 |
| `【思路】` | 分析 | 可多行 |
| `【难度】` | 难度 | 1–5，或"简单/中等/困难" |
| `【小结】` | 小结 | 可多行 |

### 示例

```
【题目】下列关于集合的说法正确的是
【选项】A. 空集是任何集合的子集  B. 0 是空集  C. {0} 是空集  D. 以上都不对
【答案】A
【解析】空集是任何集合的子集。

【题目】判断：0 是自然数
【答案】对

【题目】1 + 1 = ____
【答案】2
```

### 统一答案区（可选）

有些试卷把所有题目的答案、解析统一放在文末，而不是每题后面跟 `【答案】【解析】`。这种情况下可以在正文题目之后加一个 `【答案区】` 标签（别名：`【答案表】`/`【统一答案】`/`【答案速查】`），标签之后的内容按下面两种结构解析：

```
【答案区】
| 题号 | 1 | 2 |
|:---:|:---:|:---:|
| 答案 | B | C |

1．B因为……
2．C因为……
```

- **答案**：从 `题号 | 答案` 表格里按题号取值。
- **解析**：编号段落（`1．……` `2．……`）按题号整段作为解析；段落开头若重复抄了一遍答案（如 `10．ACD对于……`），会自动去掉这段重复前缀。
- 若某道题的答案没有出现在表格里（常见于填空题、解答题，因为答案就写在解析开头，和解析连在一起不好拆分），可以在该题号下额外写 `【答案】`/`【解析】` 标签，优先级高于表格与编号段落：

  ```
  12．【答案】20/21【解析】此人患色盲的概率……
  ```

- `【答案区】` 前面允许跟着其它标题文字（如"参考答案【答案区】"），标签不要求出现在行首。

### 题型自动推断

未写 `【题型】` 时，按以下规则判断：有选项 + 单个答案字母 → 单选；有选项 + 多个字母 → 多选；无选项 + 答案为 `对/错/√/×` → 判断；无选项 + 题干含 `____` → 填空；其余 → 解答。

### 容错与提示

解析器**尽力解析、不因个别题格式问题中断**。缺答案、答案越界、题干为空、开头存在游离文本等，会在审核页对应题目上以**黄色告警**提示，你可当场修正。

## 三步流程

### 1. 上传

先选择**解析方法**（自动多策略 / AI 智能抽取 / 本地结构识别），再选择数据源上传文件或粘贴内容。默认自动多策略优先使用本地结构识别，仅在结果质量不足时调用 AI。

选择 **AI 智能抽取**时可进一步选处理模式：

- **抽取（extract）**：默认，从素材中抽取已有题目。
- **解答（solve）**：让 AI 对题目进行解答。

### 2. 审核

AI 抽取后，逐题展示可编辑的结果，字段包括：

- 题干内容、题型、选项、答案、解析、思路、难度
- AI 建议的标签（年份、来源、年级、学期、考试类型、特征等）

你可以逐题修改、删除、调整后再确认。

### 3. 入库

确认后，题目批量写入题库，并与本次**导入任务**关联，便于后续按批次筛选和管理。

## 导入任务状态

每次导入会生成一个导入任务，状态包括：

| 状态 | 含义 |
|------|------|
| `PENDING` | 排队中 |
| `PROCESSING` | 处理中 |
| `COMPLETED` | 已完成 |
| `FAILED` | 失败 |
| `CANCELLED` | 已取消 |

## 批次管理

- **队列状态**：查看当前排队 / 处理中 / 完成 / 失败 / 取消的统计与活动任务。
- **导入历史**：分页查看历次导入，可按状态、用户筛选。
- **权限**：超级管理员可见全部导入任务；普通用户仅见自己的。

## 常见问题

- **抽取结果不准？** 调整 [Prompt 模板](/admin/prompts) 或更换更强的模型。
- **图片识别失败？** 确认已激活**视觉模型**，且图片清晰。
- **卡在处理中？**（服务器版）检查 [Worker 日志](/server/operations#后台任务-worker)。
